# Renuncia y Proteje

Es una página web encargada de alentar a las personas para que denuncien diversas peripecias ocurridas a las personas de Paraguay, situadas en la ciudad de asunción.

### ¿Comó funciona la página?

En la página se puede observar desde el inicio de esta, las denuncias de personas que pasaron por estas peripecias, informa sobre la importancia de una realización de denuncias y utiliza una base de datos para guardar experiencias de personas para demostrar que no estan solos en temas de inseguridad en el país.

### Funciones de la Página

- Posee un formulario para comentar experiencias personales

- Dichas experiencias personales son expuestas en las página (en anonino cada experiencia) para apoyar a demás personas.
